# Google Презентації: основи

Інтерактивна сторінка для повторення уроків 13–16 з інформатики (6 клас, НУШ) у стилі «Інженерний зошит».

## Що на сторінці

- Презентація і презентування — означення та міні-гра.
- Вікно Google Презентацій — пояснювач частин вікна й гра «Знайди».
- 5 етапів створення презентації — гра «Який це етап?».
- Правила оформлення й «Лікар слайдів».
- Тренажер, схожий на Google Презентації: 9 місій за завданнями практичної роботи 13–16 (назва й тема, нотатки, текстовий слайд, картинка, схема, таблиця, обрізка й рамка, вирівнювання, номери слайдів і «Джерела»).
- «Що змінили?» — властивості об’єктів.
- «Перевір себе».

Тренажер спрощений: у справжніх Google Презентаціях більше кнопок, а деякі назви можуть трохи відрізнятися. Справжні файли учнів він не змінює.

## Як відкрити

Вся сторінка — один файл `index.html`, без збирання й залежностей (шрифти підвантажуються з Google Fonts).

- Локально: відкрити `index.html` у браузері.
- Онлайн: **Settings → Pages → Build and deployment → Deploy from a branch**, гілка `main`, папка `/ (root)`. Сторінка з’явиться за адресою `https://maistyev.github.io/google-slides-basics/`.

## Для інтерактивної панелі

Під тренажером є екранні клавіші (`Shift`, `Ctrl + Z`, `Ctrl + D`, `Ctrl + M`, `Ctrl + B`, `Delete`, `Esc`), кнопка «На весь екран» і вимикач підказок «тисни сюди».
